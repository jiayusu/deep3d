# 当前状态与目标缺口

对照基准：[目标状态契约 v1.0](target-contract-v1.md)。设计方案：[系统设计 v1.0](system-design-v1.md)。本文件是实现范围盘点，不是正式冻结验收的一次观测记录。

## 已有的可运行基础

- Rust 保存类型化参数、Scene、Feature DAG、命令和不可变版本，原生工程可以重开编辑。
- 已接入 [0.3.0 机械操作集](cad-capabilities.md)：约束草图、实体操作、修饰、孔/阵列和刚性多组件结构。
- 原生/STEP 独立进程检查，命名装配与 BOM，失败结果不登记为成功物化。
- PostgreSQL 固定任务图、多个 Worker、租约、控制撤权、恢复和结果下载。
- 已有保守依赖闭包与数学模型；当前执行器仍全量重算。

已有的工程回归与三个机械源样例不冒充 10 个预注册自然语言任务或 V0.1 整体成绩。公开仓库、文档存在也不代表许可证与独立复现要求已经满足。

本轮实际检查范围与复查命令见 [机械 CAD 工程回归](../qualification/mechanical/README.md)。

## 接下来按用户结果推进

1. 将通用 CAD 工程能力接入版本化 Goal/Plan 和正式 VerifiedCommit，用户能取得固定、已验证、可编辑的公开结果。
2. 落地分类失效、属性级读写集、真实几何复用及对照重算，完成可解释的局部编辑。
3. 自然语言入口通过可替换规划者提交稳定 IR；补模型查看、差异、接管和证据入口。
4. 完成独立验收资产、种子图和运行器后冻结注册表，运行 G1～G7；在具备持续接受/恢复能力后实际启动 G6。
5. LH-001 使用同一系统另行执行，保存真实跨度、要求变更、中断恢复和成果证据。
