# Agent-Native 3D Modeling System — 目标状态契约 v1.0

**基准日期**：2026-10-27\
**本周验收时间**：2026-11-01\
**性质**：目标状态定义与验收契约；不是开发日志，也不代表任何目标已被完成。

## 0. 北极星状态

任何人能够用自然语言表达三维设计目标、约束与变化。系统在无人逐步指挥的情况下，持续将目标转化为有效的、可编辑的、可复现的三维工程成果；能够在长时间工作、执行中断、模型切换、需求修改和几何失败的扰动下保留正确状态，并提供每个重要结果的可核验证据。

关键区别：成功由**用户能够取得的结果**判定，不由工具调用次数、Agent 推理轨迹长度、代码量或渲染图的美观程度判定。

## 1. 状态空间与边界

**本周的核心领域**：参数化实体建模、结构化三维场景、多组件装配、自然语言目标驱动的可编辑模型。对复杂自由曲面、雕刻、照片级贴图、动画与有限元不作本周成功承诺。

**人类输入**：建模目标、几何/材料/空间约束、变更请求、验收规则。

**用户可观察输出**：可检查的三维模型、完整可编辑的建模过程与参数、结构组织、约束满足证明、版本与差异、复现及导出成果、任务进度和风险。

**一致性边界**：Scene Graph 表达场景组织；Feature DAG 表达可执行建模历史；Modeling IR 作为人机共用的稳定命令协议；Scene Kernel 保存权威状态。具体引擎、框架、数据库、模型服务均是可更换的手段。

## 2. 七个终局状态

### S1 目标可理解

- 每个已接受的用户目标都有结构化、可检查的约束与完成条件。
- 对缺少依据的要求，系统明确标注「待确认／不可验证／冲突」，不能自行声称达成。
- 新的目标变化会导致可观察的目标版本和完成状态变化。

### S2 几何可信

- 被宣布完成的实体具有有效的边界表示或等价的真实几何表示。
- 尺寸、体积、位置、连接和干涉等可适用的条件，由可重复执行的检测器判断。
- 美观渲染、图片相似和 AI 自评均不能单独充当几何正确证明。

### S3 保有设计意图与可编辑性

- 原始参数、Feature 关系、组件层级能被检索、修改和重建。
- 不需要原 Agent 或原提示词也可从权威状态重新生成模型。
- STEP／网格等交付格式不得替代可编辑的源资产。

### S4 变化局部、结果一致

- 任一 Feature 变化引起的失效范围与真实依赖一致。
- 不相关部分维持不变，关联的部分正确重算；最终结果与全量正确重算几何等价。
- 系统能够解释「为什么这些部分改变」。

### S5 长程自主运行

- 用户不需要指导每个 CAD 操作，系统能够持续面对多阶段设计任务。
- 每个阶段都存在经过验证的已完成状态；进度不以 Agent 声称的百分比代替。
- 终极长程验收为 LH-001：72 小时城堡建模任务。

### S6 扰动下仍可恢复

- 进程崩溃、任务重复送达、模型切换、超时、需求变更与几何错误不会破坏最后一个已提交、可验证的状态。
- 重启后可以定位未完成工作；未验证的候选结果不会成为对用户公开的权威结果。
- 并发修改具有可理解、可检测的冲突结果。

### S7 开源、复现、交付

- 第三方能够访问源代码、许可证、设计协议、示例和验证方法。
- 第三方无需原开发者手工修复隐含状态即可复现已声明成功的样例。
- 模型、结构、验收结果、差异和失败原因作为可追溯的统一交付物。

## 3. 本周必须达到的最小可证状态（V0.1；2026-11-01）

注意：以下是预先设定的**目标阈值**，不是现有系统的成绩。

| 编号 | 本周终点应当能够观察到的事实 | 通过标准 |
| --- | --- | --- |
| G1 | 自然语言意图形成可执行且可检查的目标，并产生参数化三维模型 | 10 个预注册、不同类型的零件/小装配任务；≥8 个完整满足独立定义的几何与约束验收；所有声称完成的实体几何有效 |
| G2 | 设计意图保留在可编辑源中 | 10 个交付对象均包含组件/参数/Feature 关系；至少 8 个成功任务可在无 Agent 情况下修改参数并重建 |
| G3 | 参数或需求变化具有正确的依赖传播 | 20 个预注册变更案例中 ≥18 个最终模型正确；所有受影响依赖均识别；无关 Feature 不被误判为失效；与全量重算在约定容差内等价 |
| G4 | 大图上的失效识别具有可度量性能 | 对 1,000 个节点的合成依赖图，在约定测试机上单次失效传播 P95 <100ms；统计计算不包含实际 CAD 几何重算；准确率 100% |
| G5 | 意外中断后不会丢失权威成果 | 5 种预注册中断/重复执行情境全部恢复到最后已验证提交；无重复发布；不能将未验证候选误发布 |
| G6 | 可观察的自主建模工作持续进行 | 至少一个 ≥2 小时的端到端任务，包含 ≥10 次已验证且有实际几何变化的提交、至少一次要求变更；人工不逐步操作建模软件 |
| G7 | 结果可独立复核 | 每个成功案例有任务输入、版本、源资产、几何产物、自动验收日志、复现说明；另外开发者可在干净环境复现 ≥8 个成功案例 |

这里的「不同类型」应覆盖基本布尔/拉伸/旋转/倒角或圆角/参数关系/多组件空间关系等关键能力，不得把同一零件换尺寸重复计数。变更案例应覆盖上游 Feature 修改、拓扑变化、跨组件引用和无效输入。性能指标的测试机配置必须被记录。

## 4. 北极星长程验收：LH-001 城堡任务（超出本周最低通过线）

**给定目标**：创建带有外墙、塔楼、主楼、城门、内部道路和居住区域的中世纪风格城堡场景；每个主要结构可编辑，设计关系可追踪。

**72 小时结束时的可观察状态**：

1. 模型能够重新打开并继续编辑；主要组件具有设计参数与依赖关系。
2. 场景的既定空间、尺寸、拓扑约束均被自动检查；每个未满足条件有明确证据。
3. 任务经历至少一次真实需求变化和一次执行中断；其后续版本正确继承已验证成果。
4. 进度追踪能指出每个已完成目标、未完成目标、实际故障、已采纳与未采纳候选。
5. 不需要 Agent 才能从提交版本重建、查看或导出最终成果。

**核心长程指标**：Verified Goal Completion、Recovery Success、Change Adaptation、Editability Retention、有效自主工作跨度。72 小时是验收任务的持续时间，不能用单次空转进程存活 72 小时代替。

## 5. 不变量与失败判定

无论使用何种模型、数据库或几何内核，以下条件不能被放宽：

- 一个公开的已验证版本有唯一、可追踪的权威状态。
- 未经验证的候选产物不能覆盖最后正确的版本。
- 同样的源状态、输入与确定性约束，应当得到容差内几何等价的结果。
- 每个被声称完成的要求都有来源、判定方法和检查结果。
- 可编辑性是成果的一部分：只有 STL/OBJ 图片或不可重建网格不得判为全部完成。
- 自动评分器、模型自评、渲染外观不得冒充彼此的证据。
- 无法完成的要求必须明确报告「失败／被阻塞／未知」；不得将其隐匿在成功结论中。

**项目不算成功**的典型情形：只有对话界面或工具编排；模型只能从零生成、无法修改；每次局部编辑都静默重建整座场景；进程重启后进度丢失；结果只有渲染而没有工程源；为固定测试数据写死演示脚本。

## 6. 每次观测需要报告的状态，而不是操作进度

```text
Goal version:        目标版本
Verified completion: 已有证据支持的目标比例
Geometry validity:   有效几何比例和阻断错误
Editability:         可重建、可修改的交付比例
Incremental accuracy:依赖失效与全量重算等价性
Recovery:            失败注入与恢复结果
Autonomous span:     有效无人逐步干预工作时长
Evidence:            自动验收日志与可复现资产
Open blockers:       未达成目标及真实阻碍
```

每项状态只允许「通过／未通过／证据不足」，不使用未经定义的主观进度百分比。本周阈值全数通过方可宣称 V0.1 达标；部分通过只能如实声明部分通过。

## 7. 为什么要做这个系统

现有公开项目已展示语言到参数化 CAD、几何验证、MCP 或 Agent 工作台等能力（例如 FreeCAD 生态、AgentCAD、cadex）。Parametric CAD Bench V3 已覆盖 100 个创建、创建并编辑、工程图到 CAD 的任务。我们的差异化目标应更进一步：**长程目标持续性、结构化设计意图、可证明的增量修改、故障恢复与用户掌握的可编辑交付成果**。

## 8. 任务授权与真实性边界

本文件是目标状态契约。本文件自身不证明源代码已经构建、测试通过、长期任务已开始或后台正在持续执行。实际实现与验收需由具备仓库和计算环境的运行会话产生证据；这些证据必须满足上文定义，而不能由声明替代。
